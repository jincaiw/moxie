## 启动

需要 Node.js 22 或更新版本。

```bash
npm install
npm run desktop:dev
```

桌面正式构建运行：

```bash
npm run desktop
```

浏览器预览：

```bash
npm run dev
```

浏览器版本通过文件选择器导入文档、下载导出文件。桌面版使用原生文件对话框、菜单与本地文件读写。浏览器的“会话副本”与恢复副本不等于已经保存到磁盘。

## macOS 安装包

在 Mac 上运行：

```bash
npm run package:mac
```

输出在 `release/`，包含 Apple Silicon 与 Intel 的 DMG/ZIP。当前未配置 Developer ID 签名和公证，不属于可公开分发的已签名版本。正式发布需要项目所有者的 Apple Developer 凭据。

推送 `v*` 格式的 Git tag 会由 GitHub Actions 在原生平台 Runner 上构建 arm64/x64 DMG 与 ZIP，并创建 GitHub Release、附上 SHA-256 校验文件。没有 Apple Developer 凭据时，macOS 产物仍为未签名、未公证版本。

## Windows 与 Linux 安装包

Windows 使用 NSIS 安装器，Linux 提供 AppImage；对应构建命令为 `npm run package:win` 和 `npm run package:linux`。Windows 安装版与 Linux AppImage 接入 GitHub Releases 应用内更新；Linux 其他打包格式及开发运行不启用自动更新。v0.16.121 起发布工作流会为三个桌面平台构建安装包。

## 更多桌面导出格式

桌面版可选导出 RTF、EPUB、OpenDocument（ODT）、LaTeX 和 MediaWiki 格式。它们需要单独安装 [Pandoc](https://pandoc.org/installing.html)，并确保 `pandoc` 命令在系统 `PATH` 中；安装后重启墨写。RTF/EPUB/ODT 会将本地图片嵌入文件；LaTeX 和 MediaWiki 会在导出文件旁创建 `_assets` 图片目录。远程图片不会在导出时自动下载。

- 新建、打开、保存、另存为、最近文件、递归文件夹浏览（按需打开、展开、自动刷新及会话恢复）和逐文档关闭。
- 快速打开支持按名称/路径模糊搜索当前文件夹、最近文件和已打开文档；macOS 使用 ⌘⇧O，Windows/Linux 使用 Ctrl+P。
- 链接即时排版与编辑：⌘/Ctrl 点击打开网页、文内标题或关联 Markdown 文档；支持引用链接与 HTML 标题锚点。
- 全项目搜索：在已打开的文件夹中搜索 Markdown 文件，包括尚未打开的文档；显示上下文并打开、定位匹配位置。未保存的打开文档按编辑器当前内容搜索。
- 项目内共享图片：在已打开文件夹时可用相对路径引用其他子目录的图片；单独打开文档时图片访问限制在该文档目录。
- 重启恢复上次活动文档、文件夹和展开状态；目录读取失败时保留文档并支持重试。
- 外部文件修改检测：未编辑文档自动重载，有本地编辑时保留内容并提示载入磁盘或另存为；删除后保留恢复副本。
- 可选自动保存：外部修改冲突时暂停，手动保存成功后恢复；恢复副本独立保留。
- 五种内置外观主题（浅色、深色、纸感、Solarized 浅色/深色）、字体、字号、正文宽度、专注模式与打字机模式，设置持久保存。
- 可导入、导出本地 CSS 并即时预览；支持导入最多 96 KB、128 个文件的主题文件夹，将白名单图片/字体资源内嵌后保存为本地主题。最多 20 个具名主题，单份 CSS 限制 128 KB、主题库总量限制 1.5 MB；拒绝外部资源和目录越界路径。
- HTML、PDF、DOCX 导出复用当前内置外观色板和通过安全校验的自定义 CSS。
- 原始 HTML 块及行内配对标签（含跨行标签）即时预览并净化；桌面端按文档授权路径读取其中的本地图片，点击预览可回到源码。
- PDF 导出可选择 A4/Letter/Legal、纵向/横向和 5–40 mm 页边距；桌面导出及浏览器打印均使用这些设置。
- PDF 可选显示文档标题页眉及当前页/总页数页脚，启用后自动为页眉页码留出打印空间。打印样式避免标题孤悬和表格行/图片不当拆页，长表格可跨页并重复表头；超长代码会自动换行并续排到后续页面。桌面导出会等待图片解码和字体加载（最多 8 秒）后再生成 PDF。
- 可选系统拼写检查，使用 macOS 当前拼写词典，并保持中文编辑区语言标记。
- 长文实时预览仅为可视区域及上下各 24 行生成装饰；滚动时更新视区，语法树同步解析预算限制为 12 ms，字数统计延迟 180 ms 刷新。
- 原生菜单、未保存关闭提示、保存冲突提示和原子文件写入。
- Markdown、HTML 与桌面 PDF 导出；HTML 内嵌图片与 MathML 公式。

常用编辑快捷键：⌘B 粗体、⌘I 斜体、⌘K 链接、⌘1–6 标题、⌘0 段落、⌘⇧Q 引用、⌘⇧7/8 有序/无序列表、⌘⇧L 任务列表、⌘⇧K 代码块、⌘⇧` 行内代码、⌘⇧5 删除线。

多文档操作：⌘⇧[ / ⌘⇧] 切换上一个/下一个文档；拖动标签可调整顺序，或使用 ⌥⇧← / ⌥⇧→ 移动当前标签。

## 当前边界

软件仍处于功能完善阶段，尚未达到 Typora 的完整成熟度。项目搜索最多返回 200 条结果，每篇最多读取 10 MB，单次总读取最多 100 MB；浏览器关闭时的大文档恢复依赖浏览器完成 IndexedDB 写入。桌面版已接入 GitHub 更新检查/下载/安装；当前未签名版本不能自动安装，旧版用户需先手动安装签名版。签名公证、真机更新及长文性能基准仍待验收。外部修改每两秒检查一次，窗口重新获得焦点时也会检查；目录内容每三秒自动检查，也可手动刷新。系统级中文输入法、原生窗口、PDF 和安装包须在真实 Mac 上验收。

## 验证

```bash
npm run build
npm test
npm run test:desktop
```

Linux 测试默认使用 `/usr/bin/chromium`。Mac 使用 Playwright 管理的浏览器：

```bash
npx playwright install chromium
npm test
npm run test:desktop
```

当前版本的 TypeScript 检查与生产构建通过；浏览器回归与桌面文件逻辑测试通过。桌面逻辑测试使用模拟 Electron 对话框和真实临时文件，不等同于原生 Mac 测试。
