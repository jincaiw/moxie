# 墨写 Moxie

以本地 Markdown 为中心的桌面写作工具。采用 Electron、React、TypeScript、CodeMirror 6。优先验收 macOS，同时提供浏览器预览入口。

## 启动

需要 Node.js 22 或更新版本。

```bash
npm install
npm run desktop:dev
```

桌面正式构建运行：

```bash
npm run desktop
```

浏览器预览：

```bash
npm run dev
```

浏览器版本通过文件选择器导入文档、下载导出文件。桌面版使用原生文件对话框、菜单与本地文件读写。浏览器的“会话副本”与恢复副本不等于已经保存到磁盘。

## macOS 安装包

在 Mac 上运行：

```bash
npm run package:mac
```

输出在 `release/`，包含 Apple Silicon 与 Intel 的 DMG/ZIP。当前未配置 Developer ID 签名和公证，不属于可公开分发的已签名版本。正式发布需要项目所有者的 Apple Developer 凭据。

推送 `v*` 格式的 Git tag 会由 GitHub Actions 在 macOS Runner 上构建 arm64/x64 DMG 与 ZIP，并创建 GitHub Release、附上 SHA-256 校验文件。没有 Apple Developer 凭据时，产物仍为未签名、未公证版本。

- 构建及 50 项浏览器、13 项桌面文件逻辑回归通过；真实 macOS 分页、性能专项和签名公证仍待验收。

- PDF 预览与最终导出共用渲染流程，图片和字体就绪等待、分页结果与实际 PDF 一致；浏览器版仍使用系统打印预览。

## v0.16.29 已实现

- 长文统计不再先渲染整篇 HTML；直接扫描 Markdown 可读文本，避免超长段落触发解析栈溢出。
- 编辑器将全文状态同步延迟到输入停顿后，保存、导出、关闭和切换文档前会立即同步，避免高频按键反复复制整篇文本。
- 超过 1.5 MB 的恢复副本改存 IndexedDB，启动时优先还原大文档副本；关闭窗口前等待恢复数据写入完成。
- Linux/Chromium 实测 10 MB 纯文本可打开并显示统计面板，导入约 10.5 秒；macOS 与输入延迟仍待专项测量。

- Markdown 即时排版和源码模式，行内/块级公式、代码、引用与任务列表。
- ATX（`#`）和 Setext（下划线）一级/二级标题使用一致的即时排版样式。
- 即时预览代码围栏按语言语法高亮，显示语言标签与复制按钮，点代码块可快速进入源码编辑。
- 图片预览可通过键盘聚焦，按 Enter 或空格即可返回 Markdown 图片语法编辑。
- 键盘聚焦的图片预览显示清晰的主题色轮廓。
- KaTeX 公式引擎和样式按需加载，普通文档启动不再加载公式运行时代码。
- 支持引用式图片 `![说明][名称]`，引用定义按文档缓存并参与即时预览。
- 另存为会迁移引用式图片定义所指向的本地资源，不会让新文档丢图。
- 独立 HTML `<img>` 标签可即时预览，另存为时也会迁移本地图片资源。
- 支持 Typora 风格 `==高亮文字==`，即时排版并导出为语义化 `<mark>`。
- 支持 `^上标^` 与 `~下标~` 即时排版和格式菜单应用/移除，GFM `~~删除线~~` 同步预览；HTML/PDF 导出生成 `<sup>`/`<sub>`/`<del>`，代码内容保留原文。
- 列表、任务列表与引用支持回车续写；空列表项支持再次回车退出。
- Mermaid 图表即时预览，并在 HTML/PDF 导出中生成静态 SVG；按需载入图表引擎。
- 支持 `[^label]` 脚注引用与多行定义；即时预览可跳转到定义，HTML/PDF 生成带回链的编号脚注。 脚注预览标记支持键盘聚焦与 Enter 跳转；定义跳转忽略围栏，并按大小写不敏感、连续空白归一匹配标签。
- 项目搜索可按已打开/文件夹范围筛选，按相关度、文件名或路径位置排序，并显示命中文件路径。
- macOS 桌面版可将已排版文档导出为 DOCX，支持 Word、LibreOffice 和 WPS 打开；浏览器版仍提供 HTML/PDF。
- 在独立行写入 `[TOC]` 可插入可展开的标题目录；点击目录项定位标题，HTML/PDF/DOCX 导出保留可跳转目录。
- 编辑器光标移动时，大纲会自动突出当前标题；也可以继续点击任意标题跳转。
- 输入 `(`、`[`、`{`、引号或反引号时自动补齐闭合符号；删除空白配对时退格会同时移除两侧符号。
- 直接编辑表格单元格，Tab 切换，增删行列、撤销重做和原文编辑。
- 可将电子表格或网页复制的多行 TSV 直接粘贴到表格单元格，自动扩展行列并保留含竖线内容。
- 表格支持 Tab/Shift+Tab 按行切换，最后一格按 Tab 自动创建新行；方向键可在只读格子间移动焦点。
- 图片选择、粘贴和拖入；已保存文档使用相对路径资源目录，未保存文档嵌入图片。另存为时迁移图片资源。
- 常用格式菜单与快捷键，支持整个多行选区；大纲支持 ATX/Setext 标题、查找替换、字数统计。
- 格式菜单和快捷键可插入或切换无序列表、有序列表和任务列表；多行列表自动编号并保留缩进。
- 在列表项按 Tab / Shift+Tab 可增加或减少嵌套层级；非列表段落保留编辑器原有缩进操作。
- 点击状态栏字数打开统计面板，查看分词字数、字符数（含/不含空格）、行数、段落数和预计阅读时间；状态栏同步显示光标行列。
- macOS 键盘快捷键支持一级至六级标题、段落、引用、任务列表、删除线、行内代码与代码块。
- 新建、打开、保存、另存为、最近文件、递归文件夹浏览（按需打开、展开、自动刷新及会话恢复）和逐文档关闭。
- 链接即时排版与编辑：⌘/Ctrl 点击打开网页、文内标题或关联 Markdown 文档；支持引用链接与 HTML 标题锚点。
- 全项目搜索：在已打开的文件夹中搜索 Markdown 文件，包括尚未打开的文档；显示上下文并打开、定位匹配位置。未保存的打开文档按编辑器当前内容搜索。
- 项目内共享图片：在已打开文件夹时可用相对路径引用其他子目录的图片；单独打开文档时图片访问限制在该文档目录。
- 重启恢复上次活动文档、文件夹和展开状态；目录读取失败时保留文档并支持重试。
- 外部文件修改检测：未编辑文档自动重载，有本地编辑时保留内容并提示载入磁盘或另存为；删除后保留恢复副本。
- 可选自动保存：外部修改冲突时暂停，手动保存成功后恢复；恢复副本独立保留。
- 五种内置外观主题（浅色、深色、纸感、Solarized 浅色/深色）、字体、字号、正文宽度、专注模式与打字机模式，设置持久保存。
- 可导入、导出本地 CSS 并即时预览；可将其保存为最多 20 个具名主题，重启后可切换、更新或删除。单主题限制 64 KB，拒绝外部资源加载。
- HTML、PDF、DOCX 导出复用当前内置外观色板和通过安全校验的自定义 CSS。
- 原始 HTML 块及同一行可配对的 HTML 标签即时预览并净化；桌面端按文档授权路径读取其中的本地图片。
- PDF 导出可选择 A4/Letter/Legal、纵向/横向和 5–40 mm 页边距；桌面导出及浏览器打印均使用这些设置。
- PDF 可选显示文档标题页眉及当前页/总页数页脚，启用后自动为页眉页码留出打印空间。打印样式避免标题孤悬和表格行/图片不当拆页，长表格可跨页并重复表头；超长代码会自动换行并续排到后续页面。桌面导出会等待图片解码和字体加载（最多 8 秒）后再生成 PDF。
- 可选系统拼写检查，使用 macOS 当前拼写词典，并保持中文编辑区语言标记。
- 长文实时预览仅为可视区域及上下各 24 行生成装饰；滚动时更新视区，语法树同步解析预算限制为 12 ms，字数统计延迟 180 ms 刷新。
- 原生菜单、未保存关闭提示、保存冲突提示和原子文件写入。
- Markdown、HTML 与桌面 PDF 导出；HTML 内嵌图片与 MathML 公式。

常用编辑快捷键：⌘B 粗体、⌘I 斜体、⌘K 链接、⌘1–6 标题、⌘0 段落、⌘⇧Q 引用、⌘⇧7/8 有序/无序列表、⌘⇧L 任务列表、⌘⇧K 代码块、⌘⇧` 行内代码、⌘⇧5 删除线。

## 当前边界

软件仍处于功能完善阶段，尚未达到 Typora 的完整成熟度。项目搜索最多返回 200 条结果，每篇最多读取 10 MB，单次总读取最多 100 MB；浏览器关闭时的大文档恢复依赖浏览器完成 IndexedDB 写入。自动更新、签名公证和长文性能专项基准仍待完成。外部修改每两秒检查一次，窗口重新获得焦点时也会检查；目录内容每三秒自动检查，也可手动刷新。系统级中文输入法、原生窗口、PDF 和安装包须在真实 Mac 上验收。

## 验证

```bash
npm run build
npm test
npm run test:desktop
```

Linux 测试默认使用 `/usr/bin/chromium`。Mac 使用 Playwright 管理的浏览器：

```bash
npx playwright install chromium
npm test
npm run test:desktop
```

当前版本的 TypeScript 检查与生产构建通过；浏览器回归与桌面文件逻辑测试通过。桌面逻辑测试使用模拟 Electron 对话框和真实临时文件，不等同于原生 Mac 测试。

参见 [macOS 验收清单](docs/macos-acceptance.md) 和 [实施进度](docs/implementation-plan.md)。
Typora 主要差距和后续优先级见 [功能差距盘点](docs/typora-gap-audit.md)。
