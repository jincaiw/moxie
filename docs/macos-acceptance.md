# macOS 验收

第一轮重点：即时排版、中文输入、撤销重做、文件安全。建议在 Apple Silicon macOS 上先完成以下项目，再验证 Intel。

## 编辑

- 打开欢迎文档：非活动标题隐藏 `#`，光标进入标题后标记可编辑。
- 切换到大纲，验证键盘移动光标或点击标题后，当前章节高亮随之更新；切换文档后高亮应对应新文档。
- 使用系统拼音输入法输入连续中文，验证候选词选择、回车确认、标点和中英文切换。
- 输入组合过程中移动光标或改变格式，验证不丢字、不重复、不意外提交候选词。
- 测试多行选区、Shift 选择、剪切粘贴、撤销重做；切换源码模式后继续撤销。
- 验证 ⌘B/⌘I/⌘K、⌘1–6/⌘0、⌘⇧Q/L/K、⌘⇧`/5 格式快捷键，以及工具栏菜单展示。
- 在源码模式验证括号、方括号、花括号、引号和反引号补全，并检查空配对退格行为。
- 切换文档并返回：文本、光标与当前会话的撤销历史保留。
- 直接编辑表格单元格，验证中文组合输入、Tab 切换、增删行列和撤销重做；点击“编辑原文”后验证切回排版。
- 验证任务勾选、行内/块级公式和格式菜单。
- 验证内联图片、完整引用 `![说明][名称]`、折叠引用 `![说明][]`、快捷引用 `![说明]` 均能即时预览，点击后可编辑原文。
- 验证独立 HTML `<img>` 的即时预览、键盘聚焦、点击回源码和另存为资源迁移。
- 验证 `==高亮==` 语法、格式菜单与 ⌘⇧H，确认行内代码/代码围栏不触发高亮且 HTML/PDF 显示一致。
- 验证 Mermaid 流程图即时预览、深浅主题、点击图表回到代码，以及 HTML/PDF 导出。
- 验证重复脚注引用的编号、定义续行和 HTML/PDF 双向回链；仅用键盘 Tab 聚焦脚注链接并按 Enter 跳转，检查焦点轮廓。
- 在已签名版本中检查更新、下载 arm64/x64 更新包、保持未保存文档时验证安装被阻止，保存后重启安装；确认版本号和文件内容。
- Cmd+F 查找和替换，Cmd+/ 切换模式；Cmd+Shift+F 在侧栏打开全局搜索，专注模式使用菜单/按钮。
- 大纲选项验证平铺/可折叠及重新启动恢复；从过滤和折叠状态定位当前标题，焦点及可见位置正确。
- 从系统打开单篇 Markdown，验证父目录自动加载；根内子目录文档应保留根并展开祖先。真实父目录拒绝读取时，正文和旧目录保留，错误有反馈。
- 打开两个以上文档，使用“跨文档搜索”搜索内容；验证命中上下文、文档切换和光标定位。
- 打开一个文件夹，搜索一个尚未打开的 Markdown 文件中的短语；验证结果预览、打开文件和编辑器定位。修改已打开文档但不保存后搜索，结果应反映未保存文本。
- 验证跨文档搜索范围切换、三种排序、文件路径展示，以及同名文件结果打开正确。
- 在较大目录中连续更换搜索词，等待期间旧文件夹结果与扫描统计应清空，较慢的旧搜索返回不得覆盖新结果。“已打开”范围不显示磁盘搜索状态；无匹配与扫描统计分别呈现。使用真实不可读目录检查错误只出现一次、已打开文档匹配仍保留；开启 VoiceOver 检查状态与错误朗读。

- 从侧栏顶部模式菜单切换文件、大纲与已打开；菜单关闭后标题显示当前模式，宽度拖动/左右键、Home/End、双击260px及重新启动恢复。文件夹模式只显示目录，底部加号、名称菜单和树/列表按钮固定；最近位置放在菜单内。
- 侧栏模式菜单和顶部文档标签：用左右方向键循环切换，Home/End（Mac 可用 Fn+←/→）定位首尾；验证焦点、选中状态和内容面板同步。Tab 应进入当前文档的分组和关闭控件；Alt+Shift+方向键仍可排序。
- 使用 18 个文档测试顶部定位与分组内键盘切换；从侧栏或跨文档快捷键打开组外文档，验证筛选回到“全部”，分组归属保留，顶部当前项可见。开启 VoiceOver 验证侧栏和文档标签与内容面板的名称、关联和朗读。

## 文件

- 已打开列表：上下方向键循环切换，Home/End 定位首尾，Tab 进入当前关闭按钮；关闭后焦点仍在同一区域的当前文档，顶部仅剩一篇时进入编辑器。未保存弹窗分别验证 Escape、取消按钮、取消图标；保存失败保留内容，保存成功与放弃修改后恢复焦点；关闭组内最后一篇后当前标签与焦点同步。

- 文件树用 Shift+F10 打开操作面板；上下方向键循环、Home/End 定位，末项自动滚动可见；Escape 返回文件行。鼠标或右键打开另一文件时始终只有一个面板，外部点击关闭且目标点击生效。取消新建、重命名或废纸篓弹窗后，焦点返回原文件行；VoiceOver 验证操作分组名称与按钮朗读。

- Cmd+N 新建，Cmd+O 打开，Cmd+S 保存，Cmd+Shift+S 另存为。
- 未编辑的 CRLF 文档导出 Markdown，验证内容完全一致。
- 通过另一编辑器修改当前文件后保存：弹出冲突提示，取消不会覆盖磁盘内容。
- 只读目录保存失败：显示错误，保留编辑内容。
- 未保存时关闭窗口，分别验证取消、保存全部、保留恢复副本并关闭。
- 重新启动：恢复副本可用，未保存内容有提示。
- 打开包含多层子目录的文件夹，验证展开、折叠、按需打开、刷新、关闭目录；验证空文件夹和 1000 个 Markdown 文件上限。
- 未编辑文档被外部修改：验证两秒内或重新聚焦窗口后自动重载；本地有修改时保持编辑并暂停自动保存。
- 删除磁盘文件后验证当前内容保留；重建后验证可载入。
- 载入磁盘版本提示分别选择取消、替换；另存为后验证两个版本均可保留。

- 粘贴、拖入、选择 PNG/JPEG/GIF/WebP/BMP/AVIF；保存后检查相对路径资源目录，另存为到另一目录后验证图片仍可显示。
- 打开项目文件夹，从子目录文档引用同一项目其他子目录中的图片；单独打开文档时验证不会加载其目录之外的图片。
- 开启自动保存，验证空闲后写入；用外部编辑器修改文件后验证自动保存暂停且不会覆盖。
- 重启后验证最近文件；Cmd+W 关闭当前文档并显示未保存提示。

- 重启后验证活动文档、已打开目录和展开状态恢复；移走目录后验证恢复失败提示及重试，文档内容保留。
- 添加、删除、重命名目录中的 Markdown 文件，验证三秒内自动更新；展开状态保持。
- 普通点击链接编辑原文；Cmd 点击打开网页、邮箱、文内标题和目录内关联 Markdown 文档。
- 验证重复标题锚点、引用链接、Ctrl+K 编辑已有 URL，HTML 导出后的目录链接可跳转。

## 系统与导出

- 验证交通灯、标题栏拖动、全屏、窗口缩放和原生菜单。
- 验证 Cmd+Q 未保存提醒。
- 验证 HTML/PDF 导出：中文、表格、代码块、图片、MathML 公式、Mermaid 图表、`^上标^`、`~下标~`、`~~删除线~~` 和长文分页；检查标题不孤悬、表格表头重复、超长代码可续页、图片不被不当拆分；分别用本地图片、可访问 HTTPS 图片验证导出内容就绪。
- 在导出菜单选择“预览 PDF 分页”，检查实际 PDF 的页面边界、缩放和页眉页码；修改纸张、方向、页边距后重新预览，并与最终导出的 PDF 对照；确认打印正文没有叠加网页预览内边距，内容区服从设置的页面边距。
- 验证 DOCX 导出可在 Microsoft Word、LibreOffice Writer 或 WPS 打开；检查中文、标题、列表、表格、图片和脚注。
- 修改字号和主题后重启，设置保留。
- 打开系统拼写检查后输入已知拼写错误，验证 macOS 拼写菜单与词典工作；关闭后错误标记消失，设置在重启后保持。
- 测试 100 KB、1 MB、5 MB 文档的输入与滚动，记录是否卡顿。
- 测试约 500 KB 长文，从首屏滚到文末，验证标题、粗体、公式和表格仍即时排版；连续输入时记录输入延迟。
- 验证 arm64、x64 安装包构建；测试安装、启动、退出和再次启动。
