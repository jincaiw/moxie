对照目标：**Typora 1.14.9（7785），GitHub 主题**，由用户明确提供。2026-10-10 核对。当前已发布墨写为 [v0.16.249](https://github.com/jincaiw/moxie/releases/tag/v0.16.249)；H01–H04 与 D01 已完成本轮实施和验证，原生验收仍见下方未完成清单。
