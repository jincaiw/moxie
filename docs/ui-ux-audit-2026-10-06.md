## 七个验收维度

1. **视觉一致性：** 编辑器、标签、按钮和设置使用统一主题色、细边框和圆角。次级文字对比度问题已修复。各主题的自定义 CSS 允许用户改变视觉，无法替用户保证主题色组合始终可读。
2. **布局与对齐：** 桌面采用稳定侧栏与居中阅读列；手机视口无横向溢出。手机弹窗可滚动，工具入口已补齐。桌面阅读列宽度较克制，符合长文阅读习惯。
3. **交互反馈：** 标签当前态、导出展开态、按钮禁用态和键盘焦点可辨认；菜单可用 Escape 关闭。更新检查在网页环境禁用时说明“当前环境未启用桌面更新服务”。
4. **信息层级：** 标题、正文、表格层次明确。设置页新增分组标题；“完成”是即时生效偏好设置的关闭动作，避免误解为需额外提交。
5. **可访问性：** 图标按钮有 aria 标签，菜单项可键盘聚焦，系统拼写检查可配置。五种主题的次级文字、强调文字和焦点色对比度已加入自动验证。屏幕阅读器朗读顺序和真实触屏目标尺寸仍需设备验收。
6. **异常状态：** 更新不可用说明、图片加载失败提示、主题导入错误反馈和脚注/链接边界有界面或既有回归覆盖。真实网络失败和 macOS Gatekeeper 安装态未在本次浏览器截图中模拟。
7. **文案与图标：** 主操作使用“导出”“偏好设置”等直白标签；窄屏的隐藏动作现在有文字菜单名。纯图标动作保留 aria 名称。未发现需要阻断使用的歧义。
