## 走查步骤

1. 文件树：打开完整样本和工作区，1280×900 / 900×700 检查目录、长名称、选中态和可用高度。
2. 文件夹菜单与文件操作：底部入口、排序/升降序/分组、最近位置；右键和 Shift+F10、上下/Home/End、Escape、取消文件弹窗。
3. 大纲：完整标题、层级、折叠、过滤、平铺、当前章节标记与定位；检查宽窄窗口和深浅主题。
4. 搜索与布局恢复：侧栏全局搜索、Cmd/Ctrl+Shift+F、换词与迟到响应；拖动/键盘调整宽度，重启恢复导航模式和宽度。
5. 文件打开与失败：授权文档父目录加载、已有根内子目录展开、目录拒绝时正文保留；授权入口使用桌面测试验收。
