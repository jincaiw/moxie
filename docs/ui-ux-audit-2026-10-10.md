## 七个验收维度

1. **视觉一致性：** 侧栏分组、说明和展开入口使用现有颜色、字号、圆角与焦点色；元数据不再使用标题字重。浅色和深色截图检查完成。
2. **布局与对齐：** 文件树先于最近记录；长根目录名独占标题行并保留完整路径提示；打开文档数量受控；900px 桌面没有页面横向溢出。表格在正文宽度内换行。
3. **交互反馈：** 原生 details 提供展开/关闭行为；summary 有 hover 与 focus-visible；文件操作保持 busy/disabled 状态；排序、方向键浏览和跨窗口同步回归通过。
4. **信息层级：** “已打开”、当前文件夹与最近记录明确区分。新建、刷新、关闭常用操作可见，其余工具按需展开，文件内容获得首屏空间。
5. **可访问性：** 折叠入口可聚焦并用 Enter 操作；图标动作保留可访问名称；包含原生 details 的 HTML 预览使用 group 语义；不把其 summary 点击转成源码编辑。真实读屏、平台字体以及逐像素颜色对比度未在本轮重新测量。
6. **异常状态：** 现有目录恢复失败、隐藏文件过滤、同名冲突、复制进度与取消流程保留；文件树和相关操作回归通过。样本特意使用不存在的相对图片，已确认普通图片和带链接的图片均显示替代文本；新增有效 PNG 的图片链接回归补充正常加载验证。实际文件系统图片仍需原生验收。
7. **文案与图标：** “显示与操作”“已打开”“最近打开”“最近文件夹”明确用途；低频动作使用图标加文字。样本中转义的 `\[!NOTE]` 等标记按原文显示，不擅自改成提示框。

本轮桌面重点范围评分：**8.3/10**（专家走查判断，不是自动量化分数）。主要首屏拥挤和样本渲染错误已解决；原生设备、外部图片素材和复杂自定义主题仍需补充证据。
