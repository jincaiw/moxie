# 第九轮：图片尺寸与 DOCX 导出（2026-10-11）

## L17 修复结果

原生图片尺寸对话框设置 240×120 后，Markdown 正确保存 `=240x120`，但旧 QA 导出的 DOCX 图片仍为原始 480×240。Word 转换器读取行内样式，而导出 HTML 只写宽高属性。即时预览的 `height:auto` 同样会覆盖仅高度或非原比例的高度属性。

现在尺寸语法在导出 HTML 与即时图片元素上同时写数值属性和对应 px 行内样式。未指定的维度仍按原比例计算；没有尺寸语法的图片行为不变。未改 Word 转换库或依赖。HTML 原始 img 标签及其他图片语法不在本次修复结论内。
