# L34：普通段落之间的主题留白

本机 Typora 1.14.9（7785）GitHub 主题打开自建 paragraphs.md / blank-counts.md。单 / 双空行显示相同段间距，三 / 四个空行多一个空段，五个多两个；没有把所有空行统一折叠。墨写此前逐空行固定 18px，单空行和双空行都会偏大。

实现按顶层 Paragraph 语法节点识别段落间的源空行，映射主题 p 的上下 margin，并取非负较大值模拟折叠；每增加一对额外空行保留一个正文行高加段落间距。将总高度分配到源空行的盒内，保留每一行和点击位置，不改写文档字节。限定于两个普通顶层段落之间，标题、列表、引用、围栏代码、块公式和 HTML 块没有在本批重新定义间距；复杂 p 选择器及负 margin 折叠尚不支持。
