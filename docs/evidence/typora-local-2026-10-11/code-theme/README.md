## 差距与修复

旧包同时给源码宿主行和代码预览着色、加内边距，形成两层面板。原始主题的 `code` 规则又给整块代码添加行内代码的背景、边框和字号。

L26 将源码行装饰限制在编辑态，预览保留一个表面；把主题的 `code` 映射到行内代码，把 `.md-fences` 的表面、字号、外边距和内边距映射到代码预览。块内 `code` 清除行内代码装饰，保留语法高亮。语言与复制按钮保留，其顶部空间是墨写自身交互设计，并非与 Typora 像素等价。
