2026-10-11，macOS arm64；Typora 1.14.9（7785）/GitHub，墨写独立 QA 离线导入同一主题。版本保持 0.16.249。

## 实现

- **L27**：阅读态普通列表按语法树层级累加主题 ul/ol 左内边距，默认每层 30px。支持混合嵌套，长行和段落续行从正文起点继续；有序标记保留原编号与点号/右括号。编辑行恢复原始空格和标记，文件内容不变。任务复选框、引用内列表沿用原布局，仍是后续对照项。
- **L28**：实际点击列表出现错行，大纲定位标题被顶端遮挡；网页专项也复现。CodeMirror 按盒内高度测量，YAML 块的 8px+20px 外边距造成可见位置与记录相差 28px，主题标题垂直外边距也影响坐标。YAML 间距改为内边距，主题标题用独立变量累加 margin/padding 并纳入行高，保留规则级联及源码模式隔离。
