# Typora 1.14.9 对标与桌面 UI/UX 走查

日期：2026-10-10。用户对照目标：Typora **1.14.9（7785）/ GitHub 主题**。受检产品：墨写 v0.16.248 源码及本轮改动，Linux Chromium 开发环境。范围：桌面侧栏、文件入口、大纲、快速打开、工具栏设置和历史记录失败流程。

本轮重新获取 Typora 官方文件管理、大纲和 1.14 系列说明，用于功能研究；未连接用户 Mac，未运行指定版本 Typora，不能提供两款软件实机像素差异或断言完全一致。Browser plugin not available，使用 Playwright 作为当前环境的界面走查工具。

## 走查路径

1. 恢复完整 `MARKDOWN_RENDERING_TEST.md`，查看首屏排版、属性摘要与文件树。
2. 切换大纲，检查 34 个有效标题、层级折叠、平铺、选中定位及键盘菜单。
3. 缩至 900×700，再切换深色外观；390×500 仅作极限边界压力检查。
4. 打开快速打开，按名称/完整路径筛选固定目录、最近目录及同名文件，用键盘打开目录。
5. 模拟原生菜单动作，核对工具栏偏好及编码路径，再清除最近记录。
6. 令历史保存失败，核对记录保持、错误文案与重试；隔离清除前发出的迟到查询。

原生菜单动作由桌面 harness 和浏览器 bridge 模拟验证，不能替代 macOS 菜单实机外观验收。测试输入采用授权的本地模拟路径，不访问用户真实目录。

## 优先修复与评分

本轮顺序 H04 → H01/H02/H03 → D01 → 原件显示、专项和完整回归；当前可实施项集中完成。剩余 P01/E01 优先，然后 E02–E04，E05 依实际主题，E06 性能最后。详见 [统一待办](typora-current-plan.md)。

整体临时评分：**7/10**，仅针对当前环境可观察的桌面导航与反馈。评分反映原生入口、搜索范围和失败保护得到补齐，但系统交互和严格目标主题一致性仍缺实机证据；不是量化像素相似度或完整可访问性认证。

## 证据与最终验证

46 项桌面逻辑通过，3 项新界面流程连续三轮共 9 次无重试通过；生产构建、3 款精选主题校验及原件逐字节比对通过。完整界面回归 **226 项通过、3 项性能跳过**，2 workers / 禁止重试，5.5 分钟；既有工具栏选区、完整样本渲染/导出及导航回归均通过。本轮 CI 将由提交触发，当前尚无结果；安装包仍为 v0.16.248。

专项初次失败来自测试设置：无扩展名文档被现有过滤规则排除；全页面选项定位包含对话框外元素；异步导入完成前读取了旧正文。修正为合法同名 Markdown 文件/目录、限定对话框定位及等待正文加载，没有移除验收断言；最终三轮全部通过。首次与复测日志保存在本轮证据目录。
