# Typora 功能差距盘点

对照重点：Typora 常见写作流程、设置、文档组织、导出和 macOS 分发。本文记录产品层面的差距，不代表 Typora 内部实现完全等同。

| 领域          | 当前能力                                                                                                                                                | 与 Typora 的主要差距                                                                | 优先级 |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- | ------ |
| Markdown 写作 | 即时排版、格式快捷键、ATX/Setext 标题、代码语法高亮、表格、TSV 多格粘贴、表格键盘导航、任务项、嵌套列表、Markdown/HTML 图片、脚注、目录、公式和 Mermaid | 仍需扩充 CommonMark/GFM 边界语料；主题特定语法覆盖不全                              | 高     |
| 主题与外观    | 五种内置主题；支持本地 CSS 文件导入、即时预览和持久保存                                                                                                 | 还没有主题包管理和在线图库；自定义 CSS 禁用 `@import` 与 `url()`                    | 中     |
| 文档组织      | 多文档标签、递归文件夹、全项目搜索、最近文件和会话恢复                                                                                                  | 尚无多窗口工作区、标签拖拽分组及跨窗口拖放                                          | 中     |
| 导出          | Markdown、HTML、PDF 打印和 DOCX；PDF 支持纸张、方向、页边距、标题页眉和页码；桌面端可预览实际 PDF 分页                                                  | 长表格/代码块等复杂文档分页仍需在 macOS 上校对                                      | 高     |
| 桌面平台      | Electron 桌面版，以 macOS 为当前验收目标                                                                                                                | 构建目标目前以 macOS 为主；没有自动更新、签名和公证，无法达到成熟商业软件的安装体验 | 高     |
| 长文体验      | 编辑器仅为可视区域及上下各 24 行构建即时排版装饰；KaTeX 与 Mermaid 按需加载                                                                             | 语法树渐进解析与混合媒体长文仍需 1/5/10 MB 输入和滚动专项基准                       | 高     |
| 扩展能力      | 内置 KaTeX、Mermaid 等能力                                                                                                                              | 没有 Typora 式主题安装流程，也没有插件/API 生态                                     | 低     |

## 已实施

- 支持 `==高亮==`、`^上标^`、`~下标~` 和 GFM `~~删除线~~` 即时排版；上下标菜单可反复点击应用/移除，脚注标记可键盘跳转且标签匹配遵循大小写/空白归一并跳过围栏，HTML/PDF 使用语义化标签，代码内容保持原样。
- 自定义高亮遵循反斜杠转义，转义的 `==` 定界符在即时排版和 HTML 导出中显示为字面文本，并且不会吞并后续有效高亮。
- 脚注抽取遵循 Marked 的原始 HTML 块边界；HTML 示例中的 `[^label]:` 保持原文，不会变成脚注定义。
- Tab / Shift+Tab 对列表项重新分层时，同步调整所选条目中的续行缩进，避免正文脱离列表结构。
- 增加纸感、Solarized 浅色和 Solarized 深色预设，并与原浅色/深色主题一起持久化。
- 主题色作用于编辑区、侧栏、弹窗、任务复选框、链接、选区和 Mermaid 预览。
- 保留工具栏快速浅/深切换；从其他主题切换时进入标准深色或浅色主题。
- 自定义主题可从本地 CSS 导入、即时预览、持久化和清除；限制 64 KB，拒绝外部资源与动态 CSS 表达式。

## v0.16.8 PDF 页面设置

- 设置中可选 A4、US Letter、US Legal，纵向或横向，以及 5–40 mm 页边距。
- 选项保存在本机偏好设置，同时用于桌面 PDF 导出和浏览器打印。
- 桌面导出端对 IPC 参数重新校验，避免无效纸张、方向或边距进入打印流程。

## v0.16.9 可视区域即时排版

- 即时排版装饰仅为可视区域及上下各 24 行构建，滚动时按新视区刷新。
- 光标移动与内容编辑时避免扫描全文来生成行装饰和公式替换。
- 语法树在视区内以有限时间预算确保可用；大型混合文档仍需 macOS 真机性能基准。

## v0.16.10 PDF 页眉与页码

- PDF 设置增加可选页眉与页码，页眉显示文档标题，页脚显示页码/总页数。
- 桌面版使用 Electron 打印模板；浏览器打印使用 CSS 分页边距框。
- 启用页眉页码时自动保留至少 12 mm 上下边距，避免内容与页码重叠。

## v0.16.11 表格多格粘贴

- 粘贴电子表格/网页复制的制表符数据时，按行列写入当前表格并按需扩展。
- 支持 CRLF、引号包裹字段、字段内制表符及双引号转义。
- 粘贴单元格里的竖线会转义为 Markdown 表格内容，防止破坏列结构。

## v0.16.12 表格键盘导航

- Tab / Shift+Tab 在表格单元格间按行前进和后退。
- 最后一个单元格按 Tab 会新建数据行并进入新单元格。
- 非编辑状态下可用方向键在相邻单元格间移动焦点；编辑时方向键仍移动文本光标。

## v0.16.13 Setext 标题即时排版

- `===` 一级和 `---` 二级 Setext 标题使用与 ATX 标题相同的字号、字重和间距。
- 标题下划线在非编辑状态隐藏，光标进入标题语法行时仍可编辑原文。

## v0.16.14 代码块语法高亮

- 使用 CodeMirror 语言包按需解析已标注语言的代码围栏，并应用代码 token 样式。
- 保留语言标签、复制操作、纯文本剪贴板内容和点击代码块返回源码编辑。
- 未知语言或高亮模块失败时保持原样显示，不阻塞编辑器。

## v0.16.15 图片预览键盘操作

- 即时排版图片预览加入按钮语义、可访问名称与键盘焦点。
- Enter 或空格可将焦点移回 Markdown 图片语法，鼠标点击行为保持一致。
- 浏览器回归覆盖键盘操作，确认焦点回到编辑器并可编辑图片语法。

## v0.16.16 图片焦点可见性

- 键盘聚焦图片预览时显示主题色轮廓，便于辨认当前焦点位置。
- 回归确认聚焦状态确实显示可见轮廓。

## v0.16.17 公式引擎按需加载

- KaTeX JavaScript 与 CSS 改为首次预览公式或执行导出时加载，并在本地缓存加载 Promise。
- 普通文档主 bundle 从约 1.22 MB 降至约 958 KB，gzip 从约 397 KB 降至约 319 KB。
- 导出通过 Marked 异步 token 遍历生成公式 MathML，保留 HTML/PDF/DOCX 导出流程。

## v0.16.18 引用式图片预览

- 即时排版解析 `![说明][名称]`、省略标签的 `![说明][]` 和快捷引用 `![说明]`。
- 复用当前 Markdown 文档的引用定义缓存，并沿用已有本地资源目录与路径安全规则。
- 浏览器回归验证引用式图片预览，同时覆盖公式与图片导出。

## v0.16.19 另存为迁移引用图片

- 另存为时识别被图片引用的 Markdown 定义，并复制其本地资源到新文档资源目录。
- 引用定义可位于图片使用位置之前或之后；未被图片使用的普通链接定义不迁移。
- 保留引用标签与标题，只改写图片定义的相对资源地址；代码示例保持原文。

## v0.16.20 原始 HTML 图片预览

- 支持独立 `<img src="…" alt="…">` 标签即时预览，复用既有图片路径安全策略和键盘可访问交互。
- 另存为时迁移 HTML 图片引用的本地资源，并仅改写 `src` 属性值。
- 图片预览和迁移回归覆盖 data URL、本地路径与代码样例隔离。

## v0.16.22 高亮、上标与下标语法

- 支持 `==文字==` 高亮（格式菜单、⌘⇧H）、`^上标^` 和 `~下标~`（格式菜单）。
- HTML/PDF 导出分别使用 `<mark>`、`<sup>`、`<sub>`，语法内部可继续使用行内 Markdown。
- 上下标限制为无空格内容以避开 GFM `~~删除线~~`；代码范围不触发标记。
