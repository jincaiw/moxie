## 已实施

- 支持 `==高亮==`、`^上标^`、`~下标~` 和 GFM `~~删除线~~` 即时排版；上下标菜单可反复点击应用/移除，脚注标记可键盘跳转且标签匹配遵循大小写/空白归一并跳过围栏，HTML/PDF 使用语义化标签，代码内容保持原样。
- 系统拼写检查可在偏好设置中开关，应用当前 macOS 拼写词典，并持久保存选项。
- 自定义高亮遵循反斜杠转义，转义的 `==` 定界符在即时排版和 HTML 导出中显示为字面文本，并且不会吞并后续有效高亮。
- 行内公式预览与导出共用美元符号扫描器；转义美元符号不会截断公式，连续反斜杠按奇偶数决定定界符是否转义。
- 公式起始标记遇到不满足结束条件的美元符号时会重新判断后续公式边界；回归覆盖空白、相邻公式、反斜杠奇偶转义和双美元块混排。
- GFM 自动链接回归覆盖带平衡括号的 URL 与尾部标点；即时排版和 HTML 导出都只把 URL 本体作为链接目标。
- 脚注抽取遵循 Marked 的原始 HTML 块边界；HTML 示例中的 `[^label]:` 保持原文，不会变成脚注定义。
- Tab / Shift+Tab 对列表项重新分层时，同步调整所选条目中的续行缩进，避免正文脱离列表结构。
- 增加纸感、Solarized 浅色和 Solarized 深色预设，并与原浅色/深色主题一起持久化。
- 主题色作用于编辑区、侧栏、弹窗、任务复选框、链接、选区和 Mermaid 预览。
- 保留工具栏快速浅/深切换；从其他主题切换时进入标准深色或浅色主题。
- 自定义主题可从本地 CSS 导入、即时预览、持久化和清除；主题包总量限制 96 KB、单份 CSS 限 128 KB、主题库总 CSS 限 1.5 MB，并拒绝外部资源与动态 CSS 表达式。
- 原始 HTML 块、成对行内标签和独立 HTML 空元素在编辑区以净化后的即时预览显示；桌面文档中的本地图片按授权路径载入，点击可返回源码，活动脚本不会执行。
- HTML、PDF、DOCX 导出会附加当前内置外观色板和通过安全校验的 CSS 主题，并共享 `--bg`、`--text`、`--muted`、`--border`、`--code` 和 `--accent` 变量。
- macOS 测试包现配置自有应用图标，PNG 原稿和多尺寸 ICNS 均保存在仓库中。
- PDF 允许长表格按行跨页、重复表头；长代码块可换行并续排，图片和表格行仍保持分页保护。
- 多文档工作区提供水平标签栏；标签支持切换、关闭、拖动排序和键盘排序，顺序随会话恢复。
- 标签支持命名分组、分组筛选、文档归组、重命名和移除；移除分组不会关闭或删除文档。
- CommonMark 引用链接在即时排版中保留标题；引用标签按大小写不敏感及连续空白归一解析。
- 大纲和 `[TOC]` 能识别引用块、列表项中的 ATX/Setext 标题，并跳过容器内代码围栏。
- 跨文档搜索支持已打开文档/授权文件夹范围筛选，以及按相关度、文件名和路径位置排序。
- 行内 HTML 配对标签支持跨行预览整段 Markdown，并与前后文字保持同段落；即时预览和 HTML 导出均净化不安全内容。
- 未闭合行内标签保留源码供编辑；HTML 块脚本在即时预览与 HTML 导出中均被移除，手动浏览器检查未观察到脚本执行。
- 列表项和引用块中的 HTML 区块有浏览器回归覆盖；容器后的 Markdown 正文仍可见，点击预览可回到源码。
