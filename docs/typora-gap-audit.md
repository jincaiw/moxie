# Typora 功能差距盘点

## v0.16.178 表格行列重排

Typora 官方表格编辑文档提供行列拖拽重排；Moxie 此前只能增删行列和设置对齐。本版增加“上移行 / 下移行 / 左移列 / 右移列”操作，可键盘访问，移动时保留表头结构、列对齐和原换行格式。当前交互以明确按钮完成，尚未实现 Typora 式拖拽；后续可根据实际使用反馈决定是否补充拖放。

对照来源：[Typora Table Editing](https://support.typora.io/Table-Editing/)。

## 已实施

- 支持 `==高亮==`、`^上标^`、`~下标~` 和 GFM `~~删除线~~` 即时排版；上下标菜单可反复点击应用/移除，脚注标记可键盘跳转且标签匹配遵循大小写/空白归一并跳过围栏，HTML/PDF 使用语义化标签，代码内容保持原样。
- 系统拼写检查可在偏好设置中开关，应用当前 macOS 拼写词典，并持久保存选项。
- 自定义高亮遵循反斜杠转义，转义的 `==` 定界符在即时排版和 HTML 导出中显示为字面文本，并且不会吞并后续有效高亮。
- 行内公式预览与导出共用美元符号扫描器；转义美元符号不会截断公式，连续反斜杠按奇偶数决定定界符是否转义。
- 公式起始标记遇到不满足结束条件的美元符号时会重新判断后续公式边界；回归覆盖空白、相邻公式、反斜杠奇偶转义和双美元块混排。
- GFM 自动链接回归覆盖带平衡括号的 URL 与尾部标点；即时排版和 HTML 导出都只把 URL 本体作为链接目标。
- 脚注抽取遵循 Marked 的原始 HTML 块边界；HTML 示例中的 `[^label]:` 保持原文，不会变成脚注定义。
- Tab / Shift+Tab 对列表项重新分层时，同步调整所选条目中的续行缩进，避免正文脱离列表结构。
