# Typora 功能差距盘点

## v0.16.211 快速打开

Typora 的 [文件管理说明](https://support.typora.io/File-Management/)与[快速入门](https://support.typora.io/Quick-Start/)提供快速打开面板，可模糊搜索当前文件夹和最近文件。墨写此前已有侧栏树、最近文件和跨文件内容搜索，但缺少轻量的文件名切换入口。现在快速打开汇总当前文件夹、最近打开和已打开 Markdown/TXT 文档，按文件名或路径字符序列排序，支持键盘上下选择、Enter 打开和 Escape 关闭；macOS 快捷键为 ⌘⇧O，Windows/Linux 为 Ctrl+P。窄屏工具栏也提供入口。Playwright 171 项通过、3 项性能基准跳过，桌面逻辑 29 项和生产构建通过；v0.16.211 四平台发布成功并含 20 项资产：[下载 v0.16.211](https://github.com/jincaiw/moxie/releases/tag/v0.16.211)。

## v0.16.210 选区复制为 HTML

补齐 Typora 写作时将排版结果粘贴到邮件/文档等富文本应用的工作流。格式菜单和桌面“编辑”菜单现可把选中的 Markdown 经与导出相同的安全渲染管线转换，并同时写入 HTML 与 Markdown 纯文本剪贴板；未选中文本会提示先选择，桌面 IPC 对两种数据均限制 5 MB。浏览器使用 Clipboard API，须在允许剪贴板访问的安全上下文中运行。Playwright 170 项通过、3 项性能基准跳过，桌面逻辑 29 项和生产构建通过；v0.16.210 已正式发布，Release 含 20 项资产：[下载 v0.16.210](https://github.com/jincaiw/moxie/releases/tag/v0.16.210)。真实第三方应用的粘贴样式仍建议按平台验收。

## v0.16.209 Pandoc 扩展导出格式

Typora 官方导出支持 RTF、EPUB、ODT、LaTeX 和 MediaWiki，并注明这些扩展格式需要 Pandoc。桌面版墨写现通过 Pandoc 接入这五种格式；安装为可选外部依赖，未安装时显示官方安装说明。导出使用固定格式映射和参数数组，不经 shell 执行；本地图片对 RTF/EPUB/ODT 嵌入，对 LaTeX/MediaWiki 随文件生成资源目录，远程图片转成 alt 提示且不会自动联网抓取。菜单在小窗口内可滚动。验证覆盖导出格式选择、图片隔离和资源文件；本机 Pandoc 五种实际输出均成功。详见 [Typora 导出说明](https://support.typora.io/Export/) 与 [Pandoc 安装说明](https://support.typora.io/Install-and-Use-Pandoc/)。

## 已实施

- 支持 `==高亮==`、`^上标^`、`~下标~` 和 GFM `~~删除线~~` 即时排版；上下标菜单可反复点击应用/移除，脚注标记可键盘跳转且标签匹配遵循大小写/空白归一并跳过围栏，HTML/PDF 使用语义化标签，代码内容保持原样。
- 系统拼写检查可在偏好设置中开关，应用当前 macOS 拼写词典，并持久保存选项。
- 自定义高亮遵循反斜杠转义，转义的 `==` 定界符在即时排版和 HTML 导出中显示为字面文本，并且不会吞并后续有效高亮。
- 行内公式预览与导出共用美元符号扫描器；转义美元符号不会截断公式，连续反斜杠按奇偶数决定定界符是否转义。
- 公式起始标记遇到不满足结束条件的美元符号时会重新判断后续公式边界；回归覆盖空白、相邻公式、反斜杠奇偶转义和双美元块混排。
- GFM 自动链接回归覆盖带平衡括号的 URL 与尾部标点；即时排版和 HTML 导出都只把 URL 本体作为链接目标。
- 脚注抽取遵循 Marked 的原始 HTML 块边界；HTML 示例中的 `[^label]:` 保持原文，不会变成脚注定义。
- Tab / Shift+Tab 对列表项重新分层时，同步调整所选条目中的续行缩进，避免正文脱离列表结构。
- 增加纸感、Solarized 浅色和 Solarized 深色预设，并与原浅色/深色主题一起持久化。
- 主题色作用于编辑区、侧栏、弹窗、任务复选框、链接、选区和 Mermaid 预览。
- 保留工具栏快速浅/深切换；从其他主题切换时进入标准深色或浅色主题。
- 自定义主题可从本地 CSS 导入、即时预览、持久化和清除；主题包总量限制 96 KB、单份 CSS 限 128 KB、主题库总 CSS 限 1.5 MB，并拒绝外部资源与动态 CSS 表达式。
- 原始 HTML 块、成对行内标签和独立 HTML 空元素在编辑区以净化后的即时预览显示；桌面文档中的本地图片按授权路径载入，点击可返回源码，活动脚本不会执行。
- HTML、PDF、DOCX 导出会附加当前内置外观色板和通过安全校验的 CSS 主题，并共享 `--bg`、`--text`、`--muted`、`--border`、`--code` 和 `--accent` 变量。
- macOS 测试包现配置自有应用图标，PNG 原稿和多尺寸 ICNS 均保存在仓库中。
- PDF 允许长表格按行跨页、重复表头；长代码块可换行并续排，图片和表格行仍保持分页保护。
- 多文档工作区提供水平标签栏；标签支持切换、关闭、拖动排序和键盘排序，顺序随会话恢复。
