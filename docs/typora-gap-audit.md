# Typora 功能差距盘点

对照重点：Typora 常见写作流程、设置、文档组织、导出和 macOS 分发。本文记录产品层面的差距，不代表 Typora 内部实现完全等同。

| 领域          | 当前能力                                                                                                                                                                                                                                   | 与 Typora 的主要差距                                                                                                                                            | 优先级 |
| ------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ |
| Markdown 写作 | 即时排版、格式快捷键、ATX/Setext 标题、代码语法高亮、可编辑且支持列对齐的表格、TSV 多格粘贴、表格键盘导航、任务项、嵌套列表、GFM 裸网址/邮箱自动链接、Markdown/HTML 图片、净化且可键盘操作的 HTML 块及行内预览（含 Moxie 行内格式）、脚注、目录、公式、Mermaid 和可配置系统拼写检查 | 列表/引用续行、嵌套任务、硬换行、公式、引用链接标题及容器内标题导航已有回归；v0.16.110 排除 `<pre>` 代码示例中的伪标题，其他 CommonMark/GFM 与复杂 HTML 组合仍需扩充 | 高     |
| 主题与外观    | 五种内置主题；CSS 可导入/导出、即时预览，并保存为可命名/切换/删除的本地主题；主题文件夹可导入并安全内嵌本地图片、SVG 和字体资源；在线图库提供 3 款精选主题                                                                                   | 主题包和本地 CSS 有容量上限；图库暂为维护者精选的小型目录，没有跨设备主题同步，扩展数量前需收集首轮安装反馈                                                                 | 中     |
| 文档组织      | 多文档标签、拖动排序、键盘调整顺序、中键关闭、递归文件夹、全项目搜索（可按范围筛选并按相关度/名称/路径排序）、最近文件和会话恢复                                                                                                           | 已支持新建隔离窗口及按窗口拦截未保存关闭；共享文件授权、磁盘冲突检测、跨重启窗口恢复，以及标签分组的创建、筛选、归组、重命名和移除；原生窗口体验仍需 macOS 验收 | 中     |
| 导出          | Markdown、HTML、PDF 打印和 DOCX；HTML/PDF/DOCX 使用当前外观色板及安全 CSS；PDF 长表格可跨页、表头重复，超长代码可换行续排，支持桌面分页预览                                                                                                | 复杂文档分页仍需在 macOS 上校对                                                                                                                                 | 高     |
| 桌面平台      | Electron 桌面版；接入 GitHub Releases 检查、下载进度和重启安装                                                                                                                                                                             | 自动安装要求签名 ZIP；当前发布密钥与真机更新验收仍缺，Windows/Linux 更新尚未接入                                                                                | 高     |
| 长文体验      | 编辑器仅为可视区域及上下各 24 行构建即时排版装饰；KaTeX 与 Mermaid 按需加载                                                                                                                                                                | 已有 1/5/10 MB 纯文本单次基准；混合媒体、重复采样和真实 Mac 性能列为末位验收                                                                                    | 低     |
| 扩展能力      | 内置 KaTeX、Mermaid；支持本地 CSS 主题库和官方精选主题图库                                                                                                                                                                                  | 没有插件/API 生态；图库主题数量仍少                                                                                                                                 | 低     |

## 已实施

- 支持 `==高亮==`、`^上标^`、`~下标~` 和 GFM `~~删除线~~` 即时排版；上下标菜单可反复点击应用/移除，脚注标记可键盘跳转且标签匹配遵循大小写/空白归一并跳过围栏，HTML/PDF 使用语义化标签，代码内容保持原样。
- 系统拼写检查可在偏好设置中开关，应用当前 macOS 拼写词典，并持久保存选项。
- 自定义高亮遵循反斜杠转义，转义的 `==` 定界符在即时排版和 HTML 导出中显示为字面文本，并且不会吞并后续有效高亮。
- 行内公式预览与导出共用美元符号扫描器；转义美元符号不会截断公式，连续反斜杠按奇偶数决定定界符是否转义。
- 公式起始标记遇到不满足结束条件的美元符号时会重新判断后续公式边界；回归覆盖空白、相邻公式、反斜杠奇偶转义和双美元块混排。
- 脚注抽取遵循 Marked 的原始 HTML 块边界；HTML 示例中的 `[^label]:` 保持原文，不会变成脚注定义。
- Tab / Shift+Tab 对列表项重新分层时，同步调整所选条目中的续行缩进，避免正文脱离列表结构。
- 增加纸感、Solarized 浅色和 Solarized 深色预设，并与原浅色/深色主题一起持久化。
- 主题色作用于编辑区、侧栏、弹窗、任务复选框、链接、选区和 Mermaid 预览。
- 保留工具栏快速浅/深切换；从其他主题切换时进入标准深色或浅色主题。
- 自定义主题可从本地 CSS 导入、即时预览、持久化和清除；主题包总量限制 96 KB、单份 CSS 限 128 KB、主题库总 CSS 限 1.5 MB，并拒绝外部资源与动态 CSS 表达式。
- 原始 HTML 块、成对行内标签和独立 HTML 空元素在编辑区以净化后的即时预览显示；桌面文档中的本地图片按授权路径载入，点击可返回源码，活动脚本不会执行。
- HTML、PDF、DOCX 导出会附加当前内置外观色板和通过安全校验的 CSS 主题，并共享 `--bg`、`--text`、`--muted`、`--border`、`--code` 和 `--accent` 变量。
- macOS 测试包现配置自有应用图标，PNG 原稿和多尺寸 ICNS 均保存在仓库中。
- PDF 允许长表格按行跨页、重复表头；长代码块可换行并续排，图片和表格行仍保持分页保护。
- 多文档工作区提供水平标签栏；标签支持切换、关闭、拖动排序和键盘排序，顺序随会话恢复。
- 标签支持命名分组、分组筛选、文档归组、重命名和移除；移除分组不会关闭或删除文档。
- CommonMark 引用链接在即时排版中保留标题；引用标签按大小写不敏感及连续空白归一解析。
- 大纲和 `[TOC]` 能识别引用块、列表项中的 ATX/Setext 标题，并跳过容器内代码围栏。
- 跨文档搜索支持已打开文档/授权文件夹范围筛选，以及按相关度、文件名和路径位置排序。
- 行内 HTML 配对标签支持跨行预览整段 Markdown，并与前后文字保持同段落；即时预览和 HTML 导出均净化不安全内容。
- 未闭合行内标签保留源码供编辑；HTML 块脚本在即时预览与 HTML 导出中均被移除，手动浏览器检查未观察到脚本执行。
- 列表项和引用块中的 HTML 区块有浏览器回归覆盖；容器后的 Markdown 正文仍可见，点击预览可回到源码。
- HTML 即时预览与 HTML 导出均回归覆盖混合大小写事件属性和 `javascript:` 链接，确认危险属性/协议被移除且脚本未执行。
- HTML 块、行内 HTML 和跨行 HTML 段落预览均可通过键盘聚焦；Enter 或空格会回到原始 HTML 源码位置。
- GFM 裸 `http(s)://`、`www.` 网址和邮箱可在即时排版及 HTML 导出中生成正确协议的链接；代码内 URL 保持为代码。
- 链接标签里的行内公式使用 KaTeX 即时排版；链接目标和行内代码原样保留，HTML 导出与即时预览一致。
- 打字机模式会在输入及光标导航后持续将当前光标行居中，避免方向键移至屏幕边缘时失去写作焦点。
- 标签支持鼠标中键关闭，并继续通过统一的未保存修改确认流程，减少关闭标签所需的精确点击。
- macOS 更新清单合并只保留各 runner 目标架构的 ZIP/DMG 校验记录，避免同名文件的跨架构哈希冲突。
- GFM 引用内嵌套任务、CommonMark 双空格硬换行在即时预览和 HTML 导出中保持一致；任务复选框点击可同步修改 Markdown 源码。
- HTML 行内注释和块注释在光标离开时从即时预览隐藏，引用/列表容器同样覆盖；活动行可编辑，源码模式保留原文，代码跨度和围栏中的注释示例保持可见，HTML 导出不泄漏注释文本。
- 格式菜单可插入脚注：自动选取未使用的标签、保留选中文本并添加定义，将光标定位到定义正文；无选区时直接插入引用标记。
- 表格操作工具可将当前列设为左对齐、居中或右对齐；即时预览应用列样式，Markdown 对齐标记在增删行列时保留并随列数调整。
- 主题包支持安全内嵌 SVG；导入时移除脚本、动画、样式、外链和 HTML 嵌入节点，保留静态矢量图形。
- Markdown 图片目的地由 Marked tokenizer 解析，预览及另存为资源迁移支持平衡/转义括号和尖括号包裹的含空格路径。
- 行内 HTML 标签中的 Moxie 高亮、上标、下标和行内公式在即时预览与 HTML 导出中使用同一解析规则；标题代码跨度占位符会避开原文，避免标题文字被意外替换。
- 文内标题链接的百分号编码会安全解码；格式错误的编码会提示用户，不会抛出未处理异常或改动文档。
- 跨文档 Markdown 链接会校验路径和锚点的百分号编码；格式错误时显示明确错误，不会泄漏 URI 解码异常。
- 可编辑表格单元格支持行内公式即时排版；HTML 导出同样输出 MathML 公式，代码跨度与转义美元符号保持字面内容。
- v0.16.109 为格式和导出 ARIA 菜单增加方向键、Home/End 导航、打开时首项聚焦、Escape 焦点返回及弹出菜单语义。
- v0.16.110 修复 GFM HTMLBlock 标题提取将 `<pre>` 内代码示例标题误加进大纲的问题；修复前回归失败，修复后通过。
- v0.16.61–v0.16.62 支持从文件/窗口菜单新建隔离窗口；跨重启恢复各窗口工作区，按窗口隔离未保存关闭确认，更新安装扫描全部窗口；共享授权及文件冲突校验。

截至 2026-10-07，最新完整发布版本为 v0.16.109：格式/导出菜单键盘导航和自动更新附件均已发布。v0.16.110 已提交，修复 `<pre>` 代码示例伪标题进入大纲的问题；本地定向回归和构建通过，双架构 Release 正在验证。后续优先级为：继续扩充 CommonMark/GFM 与复杂 HTML 组合；在具备设备时完成 macOS PDF 分页、原生窗口、输入法、触控板和屏幕阅读器验收；配置签名/公证密钥后验证自动更新安装；收集图库反馈和评估 Windows/Linux 支持。性能重复采样仍排在功能与体验之后。
