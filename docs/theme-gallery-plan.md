# 在线主题图库 V1 方案

## 目标与范围

提供由 Moxie 维护的精选主题目录，让用户浏览、预览并安装主题包。V1 只读、精选，不接收用户上传，不加入评论、评分或账号系统；用户安装后仍保存为本地主题，断网时不影响已有主题。

## 来源与审查

- 主题作者提交主题包、作者名称、许可证、来源链接和预览图；维护者确认许可证允许分发并检查预览图与包内容一致。
- 目录只发布维护者审查过的主题。每个主题必须有唯一 ID、不可变版本号、最低 Moxie 版本、包下载地址和 SHA-256。
- 同一版本内容不可覆盖。更新必须发布新版本并更新目录记录；撤回通过目录 tombstone 隐藏主题并禁止新安装。
- 撤回不删除用户已安装的本地主题；设置页显示撤回提示，用户可以继续使用或手动删除。

## 分发和信任边界

- V1 目录与主题包托管在 Moxie 官方 GitHub 仓库的 Release 附件中，客户端固定官方仓库地址，不接受目录返回的任意主机下载地址。
- 客户端校验主题包 SHA-256 和包内路径，然后复用现有主题包导入逻辑：限制文件数和总大小、拒绝越界路径、只允许受支持资源类型、净化 SVG，并拒绝外部 URL、`@import` 和动态 CSS 表达式。
- 安装前展示主题名称、作者、许可证、版本和来源链接；安装需要用户主动确认。目录刷新和主题更新不静默覆盖本地主题。
- 不上传文档、偏好设置或使用数据。目录读取失败、校验失败或离线时保留现有设置并给出可重试提示。

## 目录结构

目录 JSON 包含 `schemaVersion`、`generatedAt` 和主题条目。每个条目包含 `id`、`name`、`author`、`license`、`sourceUrl`、`previewUrl`、`version`、`minimumAppVersion`、`packageUrl`、`sha256`、`size`、简短说明和可选撤回状态。客户端拒绝未知 schema、重复 ID、非法版本、超限文件和非官方主机 URL。

## 设置页体验

1. “主题”设置增加“主题图库”，显示主题卡片、作者、许可证、预览图和简短说明。
2. 提供名称搜索和明暗/纸感标签筛选；无网络时展示错误及重试入口，不阻塞现有主题编辑功能。
3. 选择主题后先显示详情与安装确认；安装后保存为具名本地主题并应用，不覆盖同名主题，冲突时提示用户改名或取消。
4. 仅在用户再次打开图库时检查目录变化。已有主题有新版本时提示可更新；更新另存为新版本或要求明确确认覆盖。
5. 主题从目录撤回后不再出现在浏览列表，已安装副本保留并显示来源撤回提示。

## 实施与验收顺序

- [ ] 增加有版本的目录文件、官方 Release 发布校验和维护者审查清单。
- [ ] 增加官方主机白名单、下载尺寸上限、SHA-256 校验与目录 schema 校验。
- [ ] 设置页实现浏览、筛选、详情、安装确认、离线重试和撤回提示；复用现有净化/资源内嵌流程。
- [ ] 回归覆盖恶意主机、哈希不匹配、越界路径、危险 CSS/SVG、同名主题、断网、更新与撤回。
- [ ] 小规模发布精选主题目录，确认反馈后再扩展主题数量；V1 不引入用户上传和账号服务。

## 风险与边界

主题 CSS 虽然禁止脚本和外部资源，仍能改变编辑器视觉样式。安装确认必须清楚显示作者和许可证，并保留快速切回内置主题的入口。GitHub 仓库可用性影响目录浏览，但不影响已安装主题、文档编辑或本地主题导入。
